# Erfassungshilfe Chinesisch

Zweisprachige Erfassungshilfe (Chinesisch/Deutsch) für Grunddaten chinesischsprachiger Antragsteller der DRK-Betreuungsdienste Westfalen-Lippe gGmbH.

- Version 1.3, Stand 2026-10-29
- Läuft vollständig im Browser, lädt keine externen Ressourcen, speichert und überträgt keine Daten
- Pinyin-Umschrift: [pinyin-pro](https://github.com/zh-lx/pinyin-pro) (MIT-Lizenz), eingebettet – vollständiger Lizenztext in [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) und in der App unter „Lizenzhinweise“
